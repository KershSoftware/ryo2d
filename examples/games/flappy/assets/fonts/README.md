# Breakout's font

| File | Source | Licence |
|------|--------|---------|
| `PressStart2P-Regular.ttf` | https://github.com/google/fonts/tree/main/ofl/pressstart2p (fetched 2026-10-17, unmodified) | `OFL-PressStart2P.txt` (SIL OFL 1.1) |

The game embeds the font (`include_bytes!`), so it also works on the web.
Press Start 2P is drawn on an 8 px grid, so the game renders it as a pixel
font with an 8 px design size.
